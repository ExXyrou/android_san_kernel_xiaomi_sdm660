# 🛠️ San Kernel 4.4 - GitHub Actions Build System

[English](#english) | [Bahasa Indonesia](#bahasa-indonesia)

<a name="english"></a>
## 🇬🇧 English

Automated GitHub Actions workflow to build **San Kernel 4.4** specifically designed for **Xiaomi Redmi Note 7 (lavender)**. Powered by ZyC Clang 15.0.7 and integrated with instant Telegram notifications.

### ✨ Features
* **KernelSU Integration:** Inject KernelSU options (`kowsu`, `xxksu`, or none).
* **Flexible Packaging:** Choose between standard flashable formats (`original` or `san-kernel`).
* **Custom Tweaks:** Optional QTI Haptics support and Newcam blob configurations.
* **Telegram Alerts:** Automatically sends build results, execution time, and flashable `.zip` files straight to your Telegram chat.

### 🚀 How to Use
1. Go to the **Actions** tab in your repository.
2. Select the **Build San Kernel 4.4** workflow.
3. Click **Run workflow**, fill in your Telegram User ID, customize your build parameters, and hit **Run**.

## 🇮🇩 Bahasa Indonesia

Workflow GitHub Actions otomatis untuk membangun **San Kernel 4.4** yang dikhususkan untuk perangkat **Xiaomi Redmi Note 7 (lavender)**. Menggunakan compiler ZyC Clang 15.0.7 dan dilengkapi dengan fitur pengiriman hasil langsung ke Telegram.

### ✨ Fitur Utama
* **Dukungan KernelSU:** Bisa menyuntikkan KernelSU (`kowsu`, `xxksu`, atau dilewati).
* **Format Fleksibel:** Pilihan tipe paket flashable (`original` atau `san-kernel`).
* **Kustomisasi Tambahan:** Opsi QTI Haptics dan konfigurasi kamera baru (Newcam).
* **Notifikasi Telegram:** Mengirim file zip jadi beserta status durasi build secara otomatis ke akun Telegram Anda.

### 🚀 Cara Penggunaan
1. Buka tab **Actions** di repository GitHub Anda.
2. Pilih workflow **Build San Kernel 4.4**.
3. Klik **Run workflow**, masukkan Telegram User ID Anda, sesuaikan pengaturan yang diinginkan, lalu klik tombol hijau **Run workflow**.
